# Sound Energy Harvester — AI Science Fair Website

## Files
- `public/index.html` — complete sci-fi dashboard
- `server.js` — tiny backend that keeps the API key private
- `.env.example` — environment-variable template
- `package.json` — dependencies

## Run
1. Install a current Node.js version.
2. Open a terminal in this folder.
3. Run:
   npm install
4. Copy `.env.example` to `.env`.
5. Put your API key in `.env`.
6. Run:
   npm start
7. Open:
   http://localhost:3000

IMPORTANT: Never put the API key inside `public/index.html` or commit `.env` to a public repository.
